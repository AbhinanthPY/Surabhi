# Surabhi project instructions

- Maintain only the plain HTML, CSS and JavaScript website in `site/`. This is the user-selected implementation for all future changes.
- Edit HTML pages directly, shared styles in `site/css/`, and browser behavior in `site/js/`. Keep shared headers and footers consistent across pages.
- Do not restore the previous React/TypeScript/Vite application or create a parallel website.
- Preserve official branding, existing routes, factual content distinctions and working interactions.
- No package dependencies are required. Run `npm run build` after changes; it validates the static documents and JavaScript and copies `site/` to `dist/`.
- Preserve the existing Sites project identity and audience declared by `.openai/hosting.json`.
