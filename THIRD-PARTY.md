# Third-party assets and code

- GSAP 3.15.1 and ScrollTrigger 3.15.1 — copyright notices and Standard License link are retained in the distribution headers. License: https://gsap.com/standard-license/
- Lenis 1.3.27 — MIT; notice in `site/js/vendor/licenses/lenis.txt`.
- Lucide icons — SVG markup retained from lucide-react 0.468.0. The React package is not used by this site. MIT notice in `site/js/vendor/licenses/lucide-react.txt`.
- The compiled stylesheet retains the Tailwind CSS license notice from its original compilation. No Tailwind compiler or runtime is required.

Photograph and font provenance remains in `ASSETS.md`. Original organization artwork is user supplied.
